# Nudge 2.0.0

Nudge 2.0.0 是跨平台正式版，提供待办、专注计时、任务学习包和可编辑学习路线。

## 主要功能

- Windows、macOS、Linux、Android 和 iOS 正式构建。
- 三栏学习包：资料与工具、精选视频、学习路线。
- 本地优先 SQLite 数据、v1 数据迁移、JSON 导入导出和自动备份。
- 可选 AI 推荐与 WebDAV/Nextcloud 端到端加密同步。
- 桌面托盘、通知、快捷键和专注计时恢复。

发布包和 `SHA256SUMS.txt` 会上传到 GitHub Release。Windows/macOS 签名、Android release keystore 和 iOS 真机签名需要在对应平台接入证书后启用。
