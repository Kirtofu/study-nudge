# Nudge 2.1.0-rc.1

这是 `v2.1.0` 的跨平台候选版本，用于验证安全迁移、WebDAV schema 3 同步和五平台构建产物。

## 主要改进

- AI 密钥、WebDAV 密码和可选同步口令迁移到系统密钥库；旧 vault 仅在写入与回读验证成功后删除。
- WebDAV 同步加入持久化 HLC、版本向量、标签关联墓碑、可恢复冲突和加密信封 v2。
- JSON 备份升级到 schema 3，并继续兼容 v1/v2 导入。
- 启动改为一次 `app.bootstrap()`；任务写入局部合并，详情自动保存按任务串行。
- 路线图自动布局改为单次 Rust 命令，学习包、设置、命令面板与专注历史按需加载。
- 设置按“通用、AI、同步、数据”分栏，新增 7 天、30 天和全部专注历史。
- 新数据库不再创建示例任务；空状态可直接新建任务或导入备份。

## 同步兼容提示

`v2.1` 使用 schema 3 和加密信封 v2。连接同一个 WebDAV 远端文件的设备必须全部升级到 `v2.1` 后再继续同步。`v2.0` 客户端遇到新信封会停止同步，避免覆盖墓碑与冲突元数据。

## 候选版验证范围

- Windows 10/11、Ubuntu 22.04+、macOS 12+、Android 10+、iOS 16+ 模拟器构建。
- v1/v2/v3 备份导入与 Windows v1 数据库迁移。
- 双设备并发编辑、标签删除传播、ETag 412 重试、断网队列与错误口令。
- 键盘操作、减少动画、移动安全区、200% 缩放与首屏体积预算。

桌面安装包尚未接入平台签名；Android 为测试 APK，iOS 为模拟器包。
