# Nudge 2.1.0

Nudge 2.1.0 强化了本地秘密存储、WebDAV 并发同步、备份迁移、启动性能与操作失败恢复，同时保留现有任务、专注记录、学习包、旧版脚本和数据文件。

## 更新内容

- 使用各平台系统密钥库持久化秘密，密钥库不可用时只保留本次会话。
- 同步升级为 schema 3、加密信封 v2、持久化 HLC、版本向量和墓碑传播。
- 启动合并为一次 bootstrap 调用，常规任务写入只更新变动实体。
- 自动保存避免旧响应覆盖新草稿，排序、完成、删除和路线编辑支持失败回滚。
- 设置页分为通用、AI、同步、数据；新增按日期分组的专注历史。
- 路线图自动布局改为单次 Rust 调用，重型界面按需加载并受 CI 体积预算约束。
- 新数据库以空状态开始，支持直接新建任务或导入备份。

## 升级提示

使用同一个 WebDAV 远端文件的所有设备需要同时升级到 v2.1。升级前应用会提示同步格式兼容性；原远端路径和同步口令保持不变。

JSON 备份为 schema 3，仍可导入 v1/v2 备份。旧 Windows 数据库、`study-nudge.ps1` 和 `data.json` 不会被删除或覆盖。
