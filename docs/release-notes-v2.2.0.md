# Nudge v2.2.0

这次更新重做了日常任务流程：更快地记下事情，持续看见此前未完成的安排，并让保存、撤销、专注和同步的状态保持一致。继续使用 Tauri、React、Rust 与 SQLite，沿用赭墨纸感界面。

## 日常记录

- 普通添加成为主操作。Enter 保存后继续输入，支持中文输入法、日期与清单选择，防止连续提交产生重复任务。
- “今天”分为“此前未完成”和“今天安排”。此前任务保留原计划日期；跨午夜和电脑唤醒后自动更新日期。
- 任务行、详情和更多菜单共用完成、删除、改期与专注操作；完成和删除各自提供五秒撤销。
- 详情自动保存显示等待、保存中、失败和重试。新草稿不会被较早返回的请求覆盖；一个操作失败不会撤销其他任务的成功修改。
- 一个搜索入口查找所有任务的标题、备注与标签，已完成结果有明确标记，支持 Ctrl+K / Ctrl+F、方向键和 Enter。
- 拖拽只调整当前分组的顺序，其他任务的相对位置保持稳定，编辑及重启后仍可恢复。

## 学习与专注

- 学习包进入独立工作区；宽屏三栏，较窄窗口使用标签页。返回时恢复列表位置。
- 保留资料、视频、路线编辑及可选 AI 生成。路线初始字号可读，“显示全图”作为独立操作。
- 任务已经保存而学习包打开失败时，会明确显示已有任务，重试只打开工作区。
- 所有专注入口显示配置的时长。重复开始相同任务不会重置计时；切换任务前可选择“保存并切换”或“继续当前专注”。
- 上一段历史与新的计时状态在同一事务保存，暂停、继续、重启及休眠恢复不会重复计时。恢复备份也会更新内存中的计时状态。

## 结构与可靠性

- 前端按任务、专注、学习和设置/同步拆分状态逻辑；原生桥接与浏览器演示使用同一类型契约。
- Rust 命令与数据库操作按业务拆分。任务写入统一返回变更集，更新有明确的串行与回滚边界。
- 新的 `app.onDataChanged` 事件包含数据域和来源。同步、导入、本地写入刷新相关窗口并保留正在编辑的字段。
- 提醒发送失败保持待发送状态，后续检查可以重试。
- 修正手机顶部入口、学习画布高度、保存错误态布局和主要按钮对比度，保留键盘焦点及减少动画支持。

## 兼容与下载

数据库和 JSON 备份继续使用 schema 3；仍可导入 v1/v2 备份。同步继续使用 v2.1 的加密信封 v2（Argon2id + XChaCha20-Poly1305），v2.1 设备无需更换同步文件。

Windows 发布物：

- [安装版](https://github.com/Kirtofu/study-nudge/releases/download/v2.2.0/Nudge-2.2.0-windows-x64-setup.exe)
- [便携 ZIP](https://github.com/Kirtofu/study-nudge/releases/download/v2.2.0/Nudge-2.2.0-windows-x64-portable.zip)
- [SHA-256 校验文件](https://github.com/Kirtofu/study-nudge/releases/download/v2.2.0/SHA256SUMS.txt)

保留 Linux x64/ARM64、macOS Intel/Apple Silicon、Android ARM64 测试 APK 和 iOS 模拟器包的发布流程。Windows 构建通过官方 HTTPS 缓存 libsodium 安装包与签名，并保留依赖自身的签名验证。

桌面安装包尚未接入平台代码签名。Android 仍为测试包，iOS 仍为模拟器包。浏览器演示在当前标签页保存数据；真实备份、联网 AI 和同步使用原生应用。
