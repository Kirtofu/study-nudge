## Windows 原生验收

使用 NSIS 安装的程序，通过 WebView2 与真实 Rust 命令测试。`scripts/smoke-windows.cjs` 为每次测试创建独立数据库、WebView2 用户目录和仅内存凭据；测试不读取正式用户数据或系统密钥库，不修改正式开机启动设置。测试结束关闭其创建的进程，证据保存在 `src-tauri/target/native-smoke-*/report.json`。

覆盖安装启动、连续录入、此前任务、任务顺序、完成/删除/恢复、暂停/继续/切换、主窗口与迷你窗联动、JSON 恢复、托盘、Win32 全局快捷键输入、系统通知投递，以及本机 WebDAV 服务上的两个独立设备数据目录。网络请求和加解密走真实原生实现，WebDAV 服务只模拟远端存储与 ETag 条件写入。

休眠经过时间的计时正确性使用可控时间的 Rust/浏览器回归验证；未让正在使用的 Windows 机器进入真实休眠。通知测试验证系统通知 API 接受投递与数据库标记；通知横幅是否展示仍取决于 Windows 的通知设置。
